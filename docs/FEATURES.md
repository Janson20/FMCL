# FMCL 功能详细说明

> 本文按界面领域列出 FMCL 的完整功能、交互细节与限制，面向想了解“具体能做什么”的用户和开发者。
> README 只保留能力概览；安装与构建见 [README.md](../README.md)，分层与模块见
> [ARCHITECTURE.md](ARCHITECTURE.md)。
>
> 本文以当前 QML 界面为准，描述实际可用的页面、操作与限制。

---

## 1. 首页（导航「游戏」）

- 当前账号卡片：显示账号名、账号类型与 UUID，可直接进入「设置 → 账号管理」。
- 最近使用版本：显示版本名与运行状态，提供「启动游戏」「强制结束游戏」与跳转版本列表的入口。
- 皮肤：选择 PNG 皮肤、显示当前文件名、移除皮肤；尺寸校验与复制到 `.minecraft/skins/` 由服务层完成。
- 签到与成就：显示连续签到天数、已解锁/总成就数与进度条，可进入成就页或查看公告。
- 首次启动且四块内容都为空时显示引导空态，不会堆叠无意义的占位卡片。

## 2. 版本与启动

### 2.1 版本识别与管理

- 已安装版本列表带搜索、排序（名称 / 原版版本 / 加载器）与数量统计；搜索无结果时不隐藏搜索框。
- 每行提供详情、模组、资源、重命名、删除等操作；详情显示实例路径、所需 Java 与模组数量。
- 版本信息直接读取 `versions/<实例名>/<实例名>.json`，不依赖文件夹名猜版本。
- 版本号按多级策略提取：`clientVersion` → `patches` → `--fml.mcVersion` → `inheritsFrom` → 下载/库信息，
  支持 HMCL 的 `patches` 合并与 `inheritsFrom` 继承链。
- 加载器检测覆盖 9 种：Forge、NeoForge、Fabric、Quilt、LegacyFabric、Cleanroom、OptiFine、LiteLoader、LabyMod；
  列表中直接显示加载器与版本号。
- 重命名实例时同步更新文件夹名、JSON 文件名与内部 `id`；删除前二次确认，并清理“最近使用版本”记录。
- 支持文件校验与打开实例目录；校验使用并发哈希，结果回写到页面状态。

### 2.2 安装与加载器

- 安装向导独立成页：手动输入版本 ID，或在「正式版 / 测试版」标签页中点选回填；每页 20 条并支持分页。
- 一键安装 8 种加载器：Forge、Fabric、NeoForge、Quilt、LiteLoader、LegacyFabric、Cleanroom、OptiFine；
  LabyMod 只做检测与版本隔离，不提供安装。
- 安装加载器时原版 Minecraft 并行安装；进度、当前文件数、取消与失败重试都在同一张进度卡中。
- 安装前按所选加载器与游戏版本查询兼容性，不兼容时给出提示，而不是等下载到一半才失败。
- 国内镜像：设置中一键开关 BMCLAPI，覆盖版本清单、游戏资源、库文件与加载器安装器；关闭后使用 Mojang 官方源。
- 适配 2026 年起 NeoForge 的 `YY.D.H` 版本命名（如 `26.1`、`26.1.1`），同时兼容旧的 `1.X.Y`。
- 安装模组加载器后自动启用版本隔离，创建 `mods/`、`config/`、`saves/`、`resourcepacks/`、`shaderpacks/` 等目录。
- 启动流程包含协议同意、公告确认与资源预下载检查；预下载支持分段多线程、进度显示与取消。
- 下载/安装期间底部可打开「深渊快线」等待小游戏（浏览器运行，进度存 `localStorage`），完成后入口自动隐藏。

### 2.3 启动与运行诊断

- Java 运行时自动扫描并匹配版本；设置中可切换自动、扫描结果或自定义可执行文件。
- 启动参数注入 G1GC 与堆内存设置；Java 8 不支持参数文件时自动回退为直接命令行启动。
- 检测到游戏窗口后关闭 stdout 管道，避免缓冲区写满拖慢最后加载阶段；可选启动后最小化启动器。
- 游戏异常退出检测：退出码非 0，或退出码为 0 但本次启动后新生成崩溃报告 / `hs_err` 时弹出诊断窗，
  旧报告按启动时间过滤，正常退出与强制结束不误报。
- 诊断窗显示退出码、崩溃报告、游戏日志与 JVM 崩溃日志入口；三种现场文件都不存在时仍提示可导出或分析。
- 本地诊断基于关键词识别 11 类常见问题（Mixin、依赖缺失、内存溢出、模组冲突等），最多展示 3 条建议。
- 导出 ZIP：崩溃报告、游戏日志、debug 日志、JVM 崩溃日志、启动器日志与系统信息；临时文件写完再原子替换。
- 上传游戏日志到 LogShare.CN，成功后自动复制分享链接；复制失败时显示可手动选中的链接。
- 净读 AI 异步分析：结果按 Markdown 渲染，可保存为 UTF-8 无 BOM 的 TXT；未登录时按钮禁用并提示。
- AI 隐私同意统一由启动链的协议负责，崩溃窗内不重复询问。

## 3. 资源与整合包

### 3.1 我的资源

- 四类资源统一管理：模组、资源包、地图、光影；顶部可切换版本。
- 版本选择顺序为“路由参数 → 最近使用 → 第一个已安装”，另提供「全局 .minecraft」查看所有版本共用目录。
- 原版实例只显示资源包与地图；安装加载器后才出现模组与光影，与版本隔离规则一致。
- 模组卡片读取 jar 内元数据：图标、名称、作者、modid、版本与简介；读取期间显示进度但不阻塞页面。
- 资源包与光影从 zip 中提取 `pack.png` 等预览图；地图 zip 自动解压到 `saves/`。
- 支持类型化搜索、分页、拖拽安装、文件选择安装、启用/禁用（`.disabled`）、删除与打开目录。
- 模组列表可一键复制到剪贴板；资源目录不存在时进入页面会自动创建。
- 模组更新检查同时查询 Modrinth 与 CurseForge，按版本比较后勾选批量更新；下载 8 并发并做哈希校验。
- 部分更新失败时保留已完成文件，用成功/失败计数与 Toast 提示，不静默丢弃。
- 检查更新所需的游戏版本与加载器取自实例 JSON（与版本列表同一套判定），因此自定义名称的
  实例（如「Fabulously Optimized」）同样能被识别；JSON 读不出来时才退回按文件夹名猜。

### 3.2 在线资源

- 「资源浏览」进入即加载热门内容，支持模组 / 资源包 / 光影类型、关键词、游戏版本与加载器筛选。
- Modrinth 与 CurseForge 双源搜索；未配置 `CURSEFORGE_API_KEY` 时自动回退为仅 Modrinth。
- 筛选条件按来源版本自动填好（游戏版本与加载器取自实例 JSON，自定义名称的实例同样能识别）；
  结果卡片显示名称、作者、下载量、简介与兼容版本。
- 详情页可选择具体版本、预览依赖并安装到指定实例；安装时递归处理 `required` 依赖，跳过找不到的依赖并提示。
- AI 搜索把关键词扩展为多个英文词并行检索，再合并去重、按下载量排序；未登录净读账号时退化为普通搜索。
- 支持本地分页与服务端分页；搜索结果不因切换来源而被清空。

### 3.3 整合包

- 客户端支持六种来源：Modrinth `.mrpack`、MultiMC/Prism、CurseForge、HMCL、MCBBS 与通用压缩包；
  服务端只接受 `.mrpack`。
- 可从本地文件安装，也可在在线浏览页搜索、选择版本后下载安装；在线版本列表按 Minecraft 版本分组，
  每次追加 50 条。安装前可命名实例，默认使用整合包名，冲突或非法名称会禁用「开始安装」。
- 解析元数据、可选组件与组件清单；`.mrpack` 的可选文件可勾选，其他格式显示只读清单。
- 自定义实例名会生成实例自己的版本 JSON（`versions/<实例名>/<实例名>.json`，从刚装好的
  加载器版本复制并改写 `id`，必要时把 client JAR 落到实例目录）：版本列表、启动与版本隔离
  都认这个实例；`jar` 字段按版本 ID 语义解析，不再产生 `versions/<实例名>.jar/` 这类幽灵目录。
- 客户端安装进度中，并行阶段（整合包文件与原版安装各半）占 90%，加载器安装占 10%；文件多线程下载，失败可重试。
- 安装完成自动刷新版本列表；服务器安装发出 `serverInstalled`，服务器列表同步刷新。
- 开服自动安装对应原版服务端、同意 EULA、生成基础 `server.properties`，并检测 Forge/Fabric/NeoForge/Quilt
  服务端加载器；Fabric 服务端缺少 Fabric API 时自动从 Modrinth 补装。
- 整合包开服后仍无法判定用途的模组会弹窗列出，可逐项禁用或跳转到服务器模组页处理。

## 4. 服务器

### 4.1 列表与生命周期

- 已安装服务器列表显示名称、版本、运行状态与数量；每行可直接启动或停止，允许多台服务器同时运行。
- 详情页提供启动、停止、加入服务器、打开目录与删除（二次确认）。
- 每个服务器独立最大内存（1G 到 16G），写入该服务器目录的 `.fmcl_server.json`，优先于全局设置。
- 端口冲突时自动顺延到空闲端口并回写 `server.properties`，不杀占用端口的进程；实际端口不等于 25565 时
  用 Toast 与列表/详情标签明确提示。
- 启动时显式传 `nogui`；Windows 下不弹服务器控制台窗口。退出启动器时关闭由本进程启动的全部服务器。
- 安装页支持手动输入版本 ID，或从正式版快速选择（每页 10 条、分页、点击回填）。
- 安装进度按“客户端 85% + 服务端 jar 15%”显示；自动同意 EULA、管理 Java、生成默认配置。

### 4.2 控制台

- 按服务器路由隔离日志，复用只读日志视图：自动滚底、不换行、最近 5000 行。
- 显示运行状态、在线玩家（`joined` / `left`，上限 20 人）与每 2 秒一次的 psutil 内存采样。
- 命令输入支持回车或发送按钮；成功执行命令会触发 `server_admin` 成就。
- 支持清屏与日志导出。
- 服务器非主动停止时，任意页面都会弹出退出质量确认；选择分析时复用崩溃服务做 AI 诊断。

### 4.3 配置编辑器

- 按 7 类展示 49 条 `server.properties`，加上内存、EULA 与目录共 52 项。
- 支持跨分类搜索（名称、键名、说明）、BOOL / INT / STR / ENUM / 内存 / 只读六类控件、高级项徽标与范围提示。
- 单项或当前分类恢复默认；INT 越界时弹窗并在输入框标红。
- 原始文本编辑：规范化换行、二次确认后写回。
- 保存只更新改动过的键，保留注释与未知键；页面对未保存修改启用离开守卫，顶栏返回、侧栏跳转、关闭按钮
  都会先确认。
- 保存后同步每服内存与详情页下拉；服务器运行中修改需重启才生效。

### 4.4 服务器模组与资源包

- 按服务器目录管理 `mods/` 与 `resourcepacks/`：搜索、分页、拖拽/文件框安装、启停、删除。
- 可导出模组清单、检查更新、批量更新，并剔除纯客户端模组。
- 服务端模组在线浏览只走 Modrinth，支持 AI 搜索、后端分页与安装到当前服务器。
- 整合包开服筛选出的“待人工确认”模组会在安装成功后集中列出。

## 5. 陶瓦联机

- 仅 Windows 支持；基于 EasyTier 虚拟组网，P2P 穿透多种 NAT。
- 环境检测与一键安装 EasyTier：多镜像并发测速，失败自动回退；升级时清理旧版本目录前先确认。
- 陶瓦编号采用 `U/` 前缀的 21 位 Base34 编码（含校验和），同时兼容传统
  `XXXXX-XXXXX-XXXXX-XXXXX-XXXXX` 编号。
- 创建大厅：输入 MC 端口与显示名称，生成编号并作为主机启动 EasyTier；主机约 5 秒就绪。
- 加入大厅：输入编号后建立连接，客机约 3 秒建连，最多 2 次寻找房主；支持编号复制。
- 成员列表主机优先，显示在线状态与访客到主机的延迟；成员 10 秒超时清理，心跳失败自动判定主机离线。
- TCP 端口转发（最多 10 路并发）+ 局域网广播模拟；加入后向 `127.0.0.1:4445` 发送广播包。
- 局域网世界扫描（3.5 秒）只展示结果，不自动点击进入；同时监听 IPv4 与 IPv6 组播。
- EasyTier 日志上限 5000 行，切换页面不丢；退出大厅与异常退出都有收尾。
- 首次联机、创建大厅、加入大厅会触发对应成就；非 Windows 显示不支持提示。

## 6. 存档备份

- 自动扫描全局 `saves/` 与各版本隔离目录，刷新时重扫。
- 备份表显示时间（本地时区）、大小、游戏版本与备注；支持恢复、校验、导出 ZIP 与删除，恢复和删除均二次确认。
- 手动备份支持备注与真实压缩进度；压缩等级可选 1 / 3 / 6 / 9。
- 自动备份可分别配置“启动游戏前”和“游戏退出后”，开关立即写入配置。
- 备份设置：存储路径（浏览/重置）、每存档保留 5 / 10 / 20 / 30 / 50 / 不限、恢复时旧存档处理
  （重命名 / 覆盖 / 回收站）。
- 恢复前校验 ZIP 完整性；备份前检查磁盘空间；超出保留数量自动删除最旧备份。
- 索引使用 `index.json` 记录元数据，兼容旧版索引；恢复时默认把当前存档重命名为 `_bak_时间戳` 保留。

## 7. 音乐

### 7.1 播放与队列

- 播放核心使用 `QMediaPlayer` 流式播放，不先整首下载；支持进度、音量、静音、淡入淡出与播放状态恢复。
- 单一播放队列，支持四种模式：顺序播放、列表循环、单曲循环、随机播放。
- 队列可跳转、上移、下移、移除；所有曲目列表共用同一套行组件，单击播放、复制、加入歌单行为一致。
- 播放历史自动记录，同曲重复播放移到最前，上限 200 条。
- 主窗底部有音乐控制条；Windows 上集成 SMTC（元数据、状态、进度、媒体键）。
- 音量均衡默认开启：按 -14 LUFS 目标分析曲目并归一增益，避免切歌时音量跳变；分析结果缓存并预取下一首。

### 7.2 发现、本地与在线

- 发现首页：每日推荐、推荐歌单、排行榜与最新音乐，默认进入。
- 本地音乐：选择文件夹后递归扫描 MP3 / FLAC / OGG / WAV / M4A / AAC，读取标签、内嵌封面与时长，
  显示扫描进度并支持「播放全部」。
- 在线搜索覆盖网易云、QQ、酷我、酷狗、咪咕五个主音源，B 站作为跨源兜底；结果带音源标签、原唱徽章与播放量。
- 自动选择可用最高音质，不再让用户手动选音质；搜索词带联想，结果按音源逐个返回。
- 结果分页显示，页码一次性生成；请求带序号守卫，旧请求不会覆盖新结果。
- 播放失败或链接无效（VIP、无版权、HTML 错误页、试听片段）时自动跨源搜索同曲，并用时长 ±15 秒校验
  排除翻唱与伴奏；切换结果会在状态栏提示。
- B 站触发 `v_voucher` 风控时弹出验证窗口并打开系统浏览器，完成滑块后自动换取 `grisk_id` 并重试。
- 原唱识别：按规范化歌名与 `originSongSimpleData` 分簇，结合发布日期、策展 ID 表、同名不同曲表、
  翻唱歌手规则与百度百科兜底判定；无法判定时不强行标记。仅在结果页内前移原唱，其余保持热度排序。
- 原唱错标/漏标可从结果页直接打开反馈问卷。

### 7.3 歌单、歌词与桌面歌词

- 歌单侧栏包含全部歌曲、我喜欢的音乐、最近播放、自建歌单与网易云歌单，并显示歌曲数。
- 歌单可新建、重命名、删除；系统歌单禁止编辑，删除前确认；右键菜单点空白、Escape 或 5 秒后关闭。
- 排序支持加入时间升降序与歌名（中文按拼音首字母）；「播放全部」使用整张歌单作为上下文。
- 「加入歌单」浮层会把已在歌单中的曲目置灰；没有歌单时可现场新建并加入。
- 歌单原子写入 `data/music/`，保留 30 秒兜底；旧 `data/music.json` 只读迁移。
- 网易云账号支持扫码登录（音乐页与设置 → 网易云音乐账号两个入口），显示 VIP 档位、可用音质与凭据有效期，
  支持手动续期；退出登录后清空远程歌单。
- 网易云远程歌单只读同步：20 首/页，失败可重试；启动、登录与每 10 分钟自动刷新，退出登录清空。
- 歌词支持 LRC、翻译与罗马音；全屏播放页带事件遮罩，点击不会穿透。
- 桌面歌词三行滚动，当前行高亮；支持开关、锁定/解锁拖拽、透明度与位置持久化。
- 全局热键：`Ctrl+Shift+Space` 播放/暂停、`Ctrl+Shift+Left/Right` 上一首/下一首、`Ctrl+Shift+Down` 停止、
  `Ctrl+Shift+Up/PageDown` 音量、`Ctrl+Shift+Alt+M` 静音。
- 不提供音效（EQ / 混响 / 变调 / 变速）与播放器迷你模式。

## 8. 工具箱（导航「工具」）

### 8.1 九个入口

- 清理游戏垃圾：按目录分组复选，扫描 `.log` / `.tmp`，可调扫描深度，跳过系统目录，确认后删除。
- 端口检测：TCP 连通性、延迟与错误信息；内置 MC Java / Bedrock / HTTP / HTTPS 预设，并支持 MC Server List Ping
  （MOTD、版本、人数、玩家样本、favicon）。
- Hash 计算：MD5 / SHA1 / SHA256 / SHA512，后台分块读取，结果可复制。
- 坐标转换：主世界与下界 X/Z 互转，Y 不变。
- 今日人品：按日期种子生成 0-100 评分与等级，持久化最近 60 天历史。
- 冷知识：内置 40 条 MC 冷知识，每日一条，可随机切换。
- 知识问答：AI 生成题目，题库持久化；剩余不超过 5 题时自动补充。
- 多线程下载：自定义 URL、User-Agent 与保存路径，支持暂停、取消清理与跨进程断点续传
  （`.fmcl-resume.json`）。
- 相关网站：29 条 MC 官网、社区、资源站与工具站，名称/描述/标签四语言，可一键打开或复制链接。

### 8.2 性能监控

- 顶栏监视器按钮与全局热键 `Ctrl+Shift+M` 两个入口。
- 无边框置顶、半透明悬浮窗，支持拖拽，默认右上角并持久化位置。
- 显示 CPU 占用/频率、内存占用/已用/总量/交换、GPU 名称/利用率/显存/温度。
- GPU 数据按 NVIDIA / AMD 多厂商探测（pynvml、nvidia-smi、rocm-smi、amd-smi、gpu-detector），
  无数据时显示占位。
- 打开时显示 10 秒快捷键提示；每秒刷新，GPU 每 2 秒更新。

## 9. 成就总览与通知

- 47 项成就、9 大分类：游戏玩家、模组玩家、服务器主、备份习惯、联机玩家、AGENT、个性化、高级用户、音乐生活。
- 部分成就分 I / II / III 阶段，按次数或进度自动升级；卡片显示当前进度、阶段与解锁/满级徽章。
- 触发点覆盖启动游戏、安装版本、备份、服务器、音乐播放、模式切换等行为；解锁时右下角 Toast 通知。
- 数据存于 `achievements.db`（SQLite WAL），使用可重入锁保护并发访问。
- 每日签到记录连续打开天数，并参与「签到达人」成就。
- 成就页包含总览、9 个分类、单成就详情与云端四条二级路由；显示总进度、上次同步时间与未登录引导。
- 云存档同步：启动时下载并逐条合并（保留阶段或进度更高者），解锁后自动推送；支持手动同步、重置云端
  与重置本地，重置需危险确认并输入短语。
- 全局通知使用同一套 Toast 栈，分 info / success / warning / error 四级，右下角堆叠、渐隐，任务完成与失败
  都会提示。

## 10. AGENT 与语音

### 10.1 对话与工具

- 三栏布局：会话列表、消息流、待办面板；会话可新建、切换、重命名、删除，历史自动保存。
- Markdown 渲染标题、段落、列表、表格与围栏代码块，不依赖 WebEngine；思考块可折叠。
- 工具调用卡片显示参数与结果，可展开、复制；SSE 流式输出，支持停止、重新生成与复制。
- 高危命令、文件修改与 `ask_user` 都需要二次确认；文件写/改/删会先预览 diff。
- 工具集共 33 个，覆盖版本、模组、资源包、光影、整合包、服务器、系统命令、联网搜索、网页抓取、
  文件读写/替换/删除/搜索/列举、会话任务与用户交互。工具循环上限 50 轮。
- 联网搜索优先使用 Bing 网页，DuckDuckGo 兜底；网页抓取可输出 Markdown、纯文本或 HTML。
- 支持四类提供商：净读、OpenAI、Anthropic 与自定义 OpenAI 兼容端点；可配置 API Key、端点与模型。
- 思考开关与强度可调；33 个工具均有 allow / ask / deny 三级权限，规则持久化。
- Skills 支持列表、新建、打开与编辑，内容注入系统上下文；技能目录为 `data/agent/skills/{name}/SKILL.md`。
- 顶栏快速输入框按 Enter 发送并自动跳转 AGENT；处理中关闭窗口需确认。
- CLI 仍可用：`python main.py --agent "..."` 或 `-A` 进入交互模式。

### 10.2 语音输入

- AGENT 输入框与主界面顶部输入框均可一键录音，识别结果自动填入。
- 基于 SenseVoice-Small 离线模型，自带标点与数字转换，DirectML / CPU 自适应。
- 首次使用自动下载模型；GitHub 下载过慢时可在设置中导入本地模型 ZIP。
- 模型就绪前语音按钮不可用，避免点击后无反馈。

## 11. 基岩版

- 仅 Windows 10 19041 及以上；提供 UWP（AppX 注册）与 GDK（XVD 解压后裸启动）两种构建。
- 已安装卡片显示名称、版本、UWP/GDK、正式/预览/测试，支持启动、删除、详情与打开版本目录。
- 版本库来自 McAppx 多源回退；支持搜索、全部/UWP/GDK 筛选、每页 20 条与分页。
- 安装前需同意 MCAPPX 条款；GDK 会检测 .NET 10 SDK 并提供官方下载引导，认证组件需用户明确同意后
  从 BedrockBoot 官方 NuGet 按需下载。
- 微软设备码登录：展示代码、复制、打开链接并轮询结果。
- 安装使用真实下载进度；多线程断点续传并做 MD5 校验。
- GDK 的 XVD 解压委托 .NET 辅助程序（BedrockLauncher.Core），优先 AES-NI，老 CPU 回退软件解密，
  并修复 0 字节段页对齐问题。
- 环境检测与修复：开发者模式、Gaming Services、VC++ 运行时、GameInput；Gaming Services 缺失时在下载前
  用 winget 自动安装，失败再引导微软商店。

## 12. 设置、账号与个性化

### 12.1 设置

- 9 个分区：启动器、Java、主题、音乐账号、日志、关于、账号、AI、插件。
- 设置使用整域草稿：改动只进草稿，可预览主题/强调色/语言；点保存才写盘，取消还原，带未保存修改离开会提示。
- 启动器分区：启动后最小化、国内镜像开关、下载线程数（1-255）、界面语言。
- Java 分区：自动 / 扫描 / 自定义三种模式、自定义路径浏览、扫描结果单选应用与刷新。
- 主题分区：5 套预设、导入 `.json` 主题、自定义 Hex 强调色、随机颜色与版本动态主题。
- 语言支持简体中文、English、繁體中文、日本語，切换即时生效（不再要求重启）。
- 日志、关于与插件分区分别提供日志入口、版本信息/更新检查、插件管理器与市场入口。

### 12.2 账号与皮肤

- 微软正版登录：PKCE OAuth，另提供设备代码登录作为备用。
- 离线登录：本地生成 UUID，无需网络验证。
- Yggdrasil 外置登录：支持皮肤站等第三方验证服务器，并自动注入 `authlib-injector`。
- 微软 Token 在启动前自动检查并用 `refresh_token` 续期；账号独立存于 `accounts.json`，Token 加密。
- 账号可添加、删除、切换、设为当前；支持导入/导出加密的 `.fmcl_accounts` 文件（密码保护）。
- 角色名由当前账号自动决定：微软用 Xbox 昵称，离线用自定义名，Yggdrasil 用认证服用户名。
- 皮肤支持 64x64 / 64x32 / 128x128 / 128x64 PNG，自动复制到 `.minecraft/skins/`。

### 12.3 净读账号

- 设置 → 净读账号：用户名/密码登录，登录中禁用按钮，错误按账号密码、HTTP、网络、无 Token 分类提示。
- 登录后展示用户名、UUID、等级、个性签名与 AI 积分，可刷新或退出。
- Token 写入 `config.jdz_token`（Fernet 加密），用户名加密保存，用户信息只做内存缓存。
- HTTP 401 时提示登录过期并清除本地 Token；登录即时生效，不进入设置草稿。

### 12.4 主题与界面

- 默认主题与海洋蓝调、森林绿意、薰衣草紫、日落暖橙等预设，一键切换。
- 自定义强调色支持 `#RRGGBB` 校验、空值清除与随机生成。
- 版本动态主题按当前 Minecraft 版本调整强调色（1.13 至 1.21 等版本各有配色）。
- 主题选择、强调色与动态主题开关持久化到 `config.json`。
- 界面使用 QML 自绘组件与 FluentUI 模块，颜色只来自主题变量，统一走图标与 110ms 过渡；
  不使用渐变，也不在界面中使用 emoji。
- 12 个一级领域按“游戏 / 资源与联机 / 工具与扩展”三组展示；插件页归入“插件”组，当前平台不可用的领域
  （如非 Windows 的基岩版）不会出现在导航里。

## 13. 插件、更新与系统集成

### 13.1 插件系统

- 插件以 `.fmpl` 压缩包分发，包含 `plugin.json` 与 Python 模块；支持本地安装与在线市场。
- 插件管理器可浏览、启用、禁用、卸载与查看权限；启用/禁用/安装后热加载，无需重启。
- 权限分低/中/高三级：低风险一次性确认、中风险可撤销、高风险每次弹窗。
- 20+ 钩子点覆盖应用、游戏、版本、服务器、下载与 UI 生命周期。
- 单插件异常被隔离，不影响其他插件与启动器；插件间做版本约束、循环依赖检测与拓扑排序。
- 更新失败自动回滚旧版本；每个插件有独立 `data/` 与 `configs/` 目录。
- UI API v2：插件可用 QML 提供页面，通过 `Plugins.call` 取数，并登记到一级导航；声明
  `ui_api: 1` 的插件页面不加载，但非 UI 钩子不受影响。

### 13.2 自动更新

- 自动更新目前仅支持 Windows：启动时检查 GitHub Release（可关闭），发现新版本显示版本号与更新日志。
- 设置 → 关于可手动检查、下载并启动 NSIS 安装包；安装程序启动后走正常退出链，并解锁
  `advanced_updater` 成就。
- Linux 与 macOS 不提供自动安装，需通过 tarball、安装脚本或源码更新；更新按钮会提示不支持。

### 13.3 状态与系统集成

- 底部状态栏显示操作结果，成功/失败/警告 10 秒后自动清空，加载中状态常驻。
- Toast 用于不适合占用状态栏的异步结果；同一事件只在壳层挂一次，避免重复提示。
- Windows 支持 SMTC 与全局热键；性能监控与音乐热键在 Linux 需要相应权限，非 root 环境可能不可用。

## 14. 安全、性能与数据

### 14.1 安全

- 所有 HTTP 请求默认验证 SSL 证书。
- Token 使用随机密钥文件 + Fernet 对称加密存储；`.fmcl_key` 可随 `config.json` 一起迁移。
- 用户输入经过白名单与路径校验，防止命令注入与路径穿越。
- 模组下载校验 SHA1 / SHA512，更新包校验 SHA256；下载器支持连接池、指数退避重试与 Range 断点续传。
- 配置、备份索引等使用临时文件 + 重命名原子写入；整合包安装失败自动清理部分文件与目录。

### 14.2 性能

- JSON 优先使用 orjson，缺失时回退标准库。
- 文件校验使用 `ThreadPoolExecutor` 并发哈希。
- 下载使用 asyncio + aiohttp 并发处理批量任务。
- JVM 参数注入 G1GC 与固定堆；游戏窗口出现后关闭 stdout 管道。
- 非首屏模块延迟导入；镜像 URL 转换结果缓存；版本查找使用 set 实现 O(1)。

### 14.3 数据与日志

- 数据目录优先使用程序所在目录（便携模式）；不可写时回退用户数据目录：
  Windows `%LOCALAPPDATA%\FMCL`，macOS `~/Library/Application Support/FMCL`，Linux `~/.config/fmcl`。
- 配置保存为 `config.json`，启动器日志为 `latest.log`；Linux 日志优先
  `~/.local/share/fmcl/fmcl.log`，不可读时回退 `~/.fmcl/latest.log`。
- 结构化日志以 JSONL 追加到 `latest_structured.log`，覆盖崩溃、下载失败、模组安装、服务器启动、
  备份恢复、启动命令与自动更新等关键路径。
- 安装器卸载只删除程序文件与快捷方式，保留 `config.json`、`.minecraft`、账号、歌单与成就等用户数据。

## 15. 平台支持与已知限制

- Windows：QML 版仅提供 x64 安装包（PySide6 6.7.3 无 win32 轮子）。32 位系统请使用 2.12.6 安装包，
  数据目录与新版相同。
- Linux：提供 x86_64 源码构建与 tarball；安装脚本注册 `fmcl` 命令。全局热键在非 root 环境可能不可用。
- macOS：只支持从源码运行，暂不提供 `.dmg`。
- 基岩版与陶瓦联机仅 Windows；非 Windows 会显示明确的不支持提示，而不是空白页。
- 音乐不提供音效与迷你模式。
- 当前只提供 QML 界面；插件页面使用 QML 扩展协议，命令行模式保留在 `main.py`。
- 首次从旧版升级时，旧数据目录可继续使用；安装目录保持 `%LOCALAPPDATA%\Programs\FMCL`，卸载不会递归删除用户数据。
